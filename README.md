Leonida Legend — the complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description and grade exactly as PlayStation publishes them, a guide in our own words with its sources cited beside it, a three-step roadmap to the platinum (~200 hours, difficulty 4/10), the one potentially missable trophy flagged, and a checklist that saves in the browser with export/import, kind filters, and a spoiler setting that hides story trophies until earned. Zero online trophies — the whole list is single-player.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no network at run time: serve `app/` with any static file server and open `app/index.html`.
